## 原生 IP、双 ISP、住宅 IP：买之前先分清

这三个词经常被混着用，实际指向不同。

原生 IP 指 IP 的注册归属地与实际使用地一致，德国机器拿德国段，地区识别不会错位。双 ISP 指 IP 数据库里同时带有网络运营商和互联网服务提供商属性，相比纯机房段，平台风控的判定更宽松。住宅 IP 是另一回事，那是真正分配给家庭宽带的地址段。
